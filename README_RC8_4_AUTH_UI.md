# PowerAI RC8.4 — Auth UI + Confirm Password

- Tách rõ 2 chế độ Đăng nhập và Tạo tài khoản bằng tab riêng.
- Đăng nhập chỉ có Email + Mật khẩu.
- Đăng ký có Email + Mật khẩu + Nhập lại mật khẩu.
- Không cho đăng ký nếu 2 mật khẩu không trùng hoặc mật khẩu dưới 6 ký tự.
- Hiển thị trạng thái mật khẩu trùng/không trùng ngay khi nhập.
- Khách vẫn chỉ xem; mọi thao tác PowerAI chỉ mở sau khi đăng nhập.
- Không thay đổi thuật toán A/B/C/L hay schema cloud hiện có.
