# PowerAI 6/55 — RC6.4.1 Result Polish

Thay đổi giao diện kết quả:
- hàng chỉ số mà A/B/C đang dẫn được tô nền nhẹ
- card track dẫn nhiều chỉ số nhất được highlight
- nếu nhiều track có cùng số chỉ số dẫn, các card cùng được highlight
- kết quả thủ công hiển thị:
  "Nhập thủ công • chờ đối chiếu dữ liệu chính thức"
- khi feed có kỳ đó, hệ thống tự đổi thành:
  "Đã xác nhận từ dữ liệu chính thức"
- nếu dữ liệu chính thức khác kết quả nhập tay:
  hệ thống tự lấy feed làm chuẩn và báo bằng toast
- bảng lịch sử dùng nhãn "Chờ xác nhận" / "Đã xác nhận"

Không thay đổi thuật toán A/B/C hoặc cách chấm điểm vé.
