# PowerAI 6/55 — SEO minimal

Bản này giữ nguyên thuật toán RC7.0 và chỉ thêm lớp SEO cơ bản cho domain `https://powerai655.vercel.app/`.

Đã thêm:
- Title + meta description thân thiện tìm kiếm
- canonical về URL gốc `/`
- robots / googlebot index,follow
- Open Graph + Twitter metadata
- Schema.org WebApplication JSON-LD
- `robots.txt`
- `sitemap.xml`
- `favicon.svg` + `site.webmanifest`
- `vercel.json` redirect `/index.html` -> `/`
- footer mô tả ngắn có từ khóa Vietlott Power 6/55

Sau khi deploy, kiểm tra:
- https://powerai655.vercel.app/
- https://powerai655.vercel.app/robots.txt
- https://powerai655.vercel.app/sitemap.xml

Bước còn lại ngoài code: thêm website vào Google Search Console, submit sitemap và Request indexing cho trang chủ.
