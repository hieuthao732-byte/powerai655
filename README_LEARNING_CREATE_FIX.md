# RC6.6.2 Learning Create Fix

Vì sao RC6.6.1 có lúc không tạo được 20 vé L?
- nếu kỳ đang xem đã có kết quả, nút bị disable để không tạo dự đoán sau khi đã biết kết quả;
- nếu B chưa dựng xong, Learning chưa có dữ liệu nền để tạo L.

RC6.6.2 sửa trải nghiệm:
- đang xem kỳ đã có kết quả: nút hiện “Tạo 20 vé L cho #kỳ-tiếp-theo”;
- bấm một lần sẽ tự chuyển sang kỳ prospective mới nhất;
- nếu cần, hệ thống tự chuẩn bị B;
- sau đó tự tạo L01–L20.

Nếu kỳ đang chọn chưa có kết quả:
- nút ghi rõ số kỳ mà L sắp được tạo cho.

Không thay đổi thuật toán A/B/C/L.
